# Six-domain material preparation

These are native statement-to-proof material preparation results, not a completed Generic/LIFT comparison. Each domain has 80 registered items; 60 held-out and 48 debugging items are separate. Native completion and independent mathematical acceptance are distinct. Historical failures and unknown token usage remain in accounting.

Only independently accepted generated Lean files are included. Comments are removed to exclude private source excerpts; original and public hashes are both recorded. Original experiment files are unchanged. This export excludes original book text, private inputs, machine configuration, credentials, model conversations, provider responses, and private native recovery sessions. It is not a full disaster-recovery backup.

Use `tools/experiment_ops/materialize_sources.py` to reconstruct the per-item Lean files from the public dataset.
